# QA Git Practice Repository

A simple C project designed to simulate a real-world bug fix and Pull Request workflow.

## Contribution Instructions
1. Fork this repository to your GitHub account.
2. Clone your fork to your local machine.
3. Create a new branch: `git switch -c fix/division-by-zero`
4. Modify `calculator.c` to handle the zero boundary value gracefully.
5. Compile and run the code to verify your fix.
6. Commit your changes and push to your fork.
7. Open a Pull Request!
